04 · Concept

What is OOP?

Object-Oriented Programming is just a way of grouping data and the functions that act on that data into one unit — instead of scattering variables and functions everywhere.

Class

A blueprint. It describes what a thing has (attributes) and what it can do (methods) — but it isn't a real thing yet, the same way a house blueprint isn't a house.

Object

A real thing built from that blueprint. You can build many objects from one class, each with its own data.

Student (class)
↓ creates
student1
student2
student3

Attributes

student_id, name, age, grade — the data each student object carries around.

Methods

get_info(), update(), is_adult() — the actions a student object knows how to perform.

The Student class

Here's the whole class. Click any line group below to see what it does.

models/student.py 
class Student:

    def __init__(self, student_id, name, age, grade):
        self.student_id = student_id
        self.name = name
        self.age = age
        self.grade = grade

    def get_info(self):
        return (self.student_id, self.name, self.age, self.grade)

    def update(self, name, age, grade):
        self.name = name
        self.age = age
        self.grade = grade

    def is_adult(self):
        return self.age >= 18
Runs automatically the moment you write Student("S001", "An", 15, "Grade 9"). It's where a new object receives its starting data and stores it on self.
Every method's first parameter. It's how student1.get_info() knows to return student1's data and not student2's — Python passes the object itself in automatically.
Returns a tuple of the object's four attributes, in a fixed order — this is exactly the order the Treeview table will expect them in later.
update() changes the object in place (notice: no student_id parameter — an ID never changes). is_adult() derives a new fact from existing data instead of storing it separately.
⚠ Common mistake Students often forget self. when assigning attributes inside __init__ — writing name = name instead of self.name = name silently does nothing useful.

06 · Concept

Event handling

A GUI that only displays things is a poster, not an app. It needs to react — and in Tkinter, reacting means connecting a widget to a function.

sketch.py
def say_hello():
    print("Hello!")

button = tk.Button(
    root,
    text="Click Me",
    command=say_hello
)
Correct

command=say_hello

Passes the function itself — Tkinter calls it later, on click.

Wrong

command=say_hello()

Calls the function immediately, once, while building the window — and hands Tkinter its return value instead.

⚠ Common mistake command=my_function() — the parentheses are the single most common bug in every student's first Tkinter app. Say it out loud: "no parentheses, we're handing over the function, not the result."

The problem: what if we put everything in one file?

Imagine one script that builds the window, stores the student list, validates input, searches, and saves — all mixed together, top to bottom.

GUI code, data, validation, search and CRUD logic all live in the same function, referencing the same global variables.

Would this be easy to maintain?

❌ Hard to read  ·  ❌ Hard to debug
❌ Hard to modify  ·  ❌ Hard to scale

That pain is exactly what MVC exists to prevent — next section.

07 · Concept

What is MVC?

Model-View-Controller splits an app into three responsibilities that are never allowed to blur into each other.

Model

The data. Student objects, the list of students, and the rules for changing them. No GUI code here at all.

View

The GUI. Every widget the user sees and clicks. No business logic here — it doesn't decide anything.

Controller

The logic. Reads from the View, validates, updates the Model, tells the View to refresh.

User clicks a button
↓
View
↓
Controller
↓
Model
↑ updated data
Controller
↑ refresh
View
The View never talks to the Model directly. Every change flows through the Controller — that single rule is what keeps the app maintainable as it grows.
🎓 Teaching tip Don't lead with the definition. Lead with the messy one-file version from section 06, let students feel the pain, then introduce MVC as the fix — not as a rule to memorize.

models/student_manager.py
class StudentManager:

    def __init__(self):
        self.students = []

    def add_student(self, student):
        self.students.append(student)

    def get_all_students(self):
        return self.students

    def find_student(self, student_id):
        for student in self.students:
            if student.student_id == student_id:
                return student
        return None

    def update_student(self, student_id, name, age, grade):
        student = self.find_student(student_id)
        if student:
            student.update(name, age, grade)
            return True
        return False

    def delete_student(self, student_id):
        student = self.find_student(student_id)
        if student:
            self.students.remove(student)
            return True
        return False

    def count_students(self):
        return len(self.students)
Notice: StudentManager never imports tkinter. That's the test for "is this really the Model?" — if it needs to know about widgets, it isn't.
10 · View

The View

StudentView builds every widget and exposes them as attributes — self.btn_add, self.tree — but leaves their command unset. The Controller wires behavior in from the outside.

views/student_view.py
import tkinter as tk
from tkinter import ttk
from tkinter import messagebox


class StudentView:

    def __init__(self, root):
        self.root = root
        self.root.title("Student Management System")
        self.root.geometry("850x650")

        self.build_form()
        self.build_buttons()
        self.build_search()
        self.build_table()

    def build_form(self):
        form_frame = tk.Frame(self.root, padx=20, pady=20)
        form_frame.pack(fill="x")

        tk.Label(form_frame, text="Student ID").grid(row=0, column=0, sticky="w")
        self.entry_id = tk.Entry(form_frame, width=25)
        self.entry_id.grid(row=0, column=1, padx=10, pady=5)

        tk.Label(form_frame, text="Name").grid(row=1, column=0, sticky="w")
        self.entry_name = tk.Entry(form_frame, width=25)
        self.entry_name.grid(row=1, column=1, padx=10, pady=5)

        tk.Label(form_frame, text="Age").grid(row=2, column=0, sticky="w")
        self.entry_age = tk.Entry(form_frame, width=25)
        self.entry_age.grid(row=2, column=1, padx=10, pady=5)

        tk.Label(form_frame, text="Grade").grid(row=3, column=0, sticky="w")
        self.entry_grade = tk.Entry(form_frame, width=25)
        self.entry_grade.grid(row=3, column=1, padx=10, pady=5)

    def build_buttons(self):
        button_frame = tk.Frame(self.root, padx=20, pady=10)
        button_frame.pack(fill="x")

        self.btn_add = tk.Button(button_frame, text="Add", width=12)
        self.btn_add.grid(row=0, column=0, padx=5)

        self.btn_update = tk.Button(button_frame, text="Update", width=12)
        self.btn_update.grid(row=0, column=1, padx=5)

        self.btn_delete = tk.Button(button_frame, text="Delete", width=12)
        self.btn_delete.grid(row=0, column=2, padx=5)

        self.btn_clear = tk.Button(button_frame, text="Clear", width=12)
        self.btn_clear.grid(row=0, column=3, padx=5)

    def build_search(self):
        search_frame = tk.Frame(self.root, padx=20, pady=10)
        search_frame.pack(fill="x")

        tk.Label(search_frame, text="Search").pack(side="left")

        self.entry_search = tk.Entry(search_frame, width=30)
        self.entry_search.pack(side="left", padx=10)

        self.btn_search = tk.Button(search_frame, text="Search", width=10)
        self.btn_search.pack(side="left", padx=5)

        self.btn_clear_search = tk.Button(search_frame, text="Clear Search", width=12)
        self.btn_clear_search.pack(side="left", padx=5)

    def build_table(self):
        table_frame = tk.Frame(self.root, padx=20, pady=10)
        table_frame.pack(fill="both", expand=True)

        columns = ("student_id", "name", "age", "grade")

        self.tree = ttk.Treeview(
            table_frame,
            columns=columns,
            show="headings",
            height=12
        )

        self.tree.heading("student_id", text="Student ID")
        self.tree.heading("name", text="Name")
        self.tree.heading("age", text="Age")
        self.tree.heading("grade", text="Grade")

        self.tree.column("student_id", width=100)
        self.tree.column("name", width=200)
        self.tree.column("age", width=80)
        self.tree.column("grade", width=150)

        self.tree.pack(fill="both", expand=True)

    def get_form_data(self):
        return (
            self.entry_id.get().strip(),
            self.entry_name.get().strip(),
            self.entry_age.get().strip(),
            self.entry_grade.get().strip()
        )

    def clear_form(self):
        self.entry_id.delete(0, tk.END)
        self.entry_name.delete(0, tk.END)
        self.entry_age.delete(0, tk.END)
        self.entry_grade.delete(0, tk.END)

    def fill_form(self, student_id, name, age, grade):
        self.clear_form()
        self.entry_id.insert(0, student_id)
        self.entry_name.insert(0, name)
        self.entry_age.insert(0, age)
        self.entry_grade.insert(0, grade)

    def clear_table(self):
        for row in self.tree.get_children():
            self.tree.delete(row)

    def insert_row(self, student_id, name, age, grade):
        self.tree.insert("", tk.END, values=(student_id, name, age, grade))

    def get_selected_item(self):
        return self.tree.selection()

    def get_row_values(self, item):
        return self.tree.item(item, "values")

    def show_message(self, title, message):
        messagebox.showinfo(title, message)

    def show_error(self, title, message):
        messagebox.showerror(title, message)

    def ask_confirmation(self, title, message):
        return messagebox.askyesno(title, message)
Every method here either builds a widget or moves data in and out of one. There isn't a single if statement deciding whether input is valid — that's the Controller's job.
11 · Controller

The Controller

StudentController is the only piece that knows about both the View and the Model. It assigns every button's command, validates input, and keeps the table in sync with the data.

controllers/student_controller.py
from models.student import Student
from models.student_manager import StudentManager


class StudentController:

    def __init__(self, view):
        self.view = view
        self.manager = StudentManager()

        self.view.btn_add.config(command=self.add_student)
        self.view.btn_update.config(command=self.update_student)
        self.view.btn_delete.config(command=self.delete_student)
        self.view.btn_clear.config(command=self.clear_form)
        self.view.btn_search.config(command=self.search_student)
        self.view.btn_clear_search.config(command=self.clear_search)

        self.view.tree.bind("<>", self.select_student)

        self.load_sample_data()

    def load_sample_data(self):
        sample_students = [
            Student("S001", "Nguyen Van An", 15, "Grade 9"),
            Student("S002", "Tran Minh Anh", 16, "Grade 10"),
            Student("S003", "Le Hoang Nam", 17, "Grade 11"),
        ]
        for student in sample_students:
            self.manager.add_student(student)
        self.refresh_table()

    def validate_input(self, student_id, name, age, grade):
        if not student_id:
            self.view.show_error("Validation Error", "Student ID cannot be empty.")
            return False
        if not name:
            self.view.show_error("Validation Error", "Name cannot be empty.")
            return False
        if not age:
            self.view.show_error("Validation Error", "Age cannot be empty.")
            return False
        if not grade:
            self.view.show_error("Validation Error", "Grade cannot be empty.")
            return False

        try:
            age_value = int(age)
        except ValueError:
            self.view.show_error("Validation Error", "Age must be a number.")
            return False

        if age_value <= 0:
            self.view.show_error("Validation Error", "Age must be greater than 0.")
            return False

        return True

    def add_student(self):
        student_id, name, age, grade = self.view.get_form_data()

        if not self.validate_input(student_id, name, age, grade):
            return

        if self.manager.find_student(student_id):
            self.view.show_error("Duplicate ID", "This Student ID already exists.")
            return

        student = Student(student_id, name, int(age), grade)
        self.manager.add_student(student)

        self.refresh_table()
        self.clear_form()
        self.view.show_message("Success", "Student added successfully.")

    def update_student(self):
        student_id, name, age, grade = self.view.get_form_data()

        if not self.validate_input(student_id, name, age, grade):
            return

        updated = self.manager.update_student(student_id, name, int(age), grade)

        if not updated:
            self.view.show_error("Not Found", "Student ID not found.")
            return

        self.refresh_table()
        self.clear_form()
        self.view.show_message("Success", "Student updated successfully.")

    def delete_student(self):
        student_id, name, age, grade = self.view.get_form_data()

        if not student_id:
            self.view.show_error("Validation Error", "Select a student to delete.")
            return

        confirmed = self.view.ask_confirmation(
            "Confirm Delete",
            "Delete student " + student_id + "?"
        )

        if not confirmed:
            return

        deleted = self.manager.delete_student(student_id)

        if not deleted:
            self.view.show_error("Not Found", "Student ID not found.")
            return

        self.refresh_table()
        self.clear_form()
        self.view.show_message("Success", "Student deleted successfully.")

    def clear_form(self):
        self.view.clear_form()

    def select_student(self, event):
        selected = self.view.get_selected_item()

        if not selected:
            return

        values = self.view.get_row_values(selected[0])
        self.view.fill_form(*values)

    def search_student(self):
        keyword = self.view.entry_search.get().strip().lower()

        self.view.clear_table()

        for student in self.manager.get_all_students():
            if keyword in student.name.lower():
                self.view.insert_row(*student.get_info())

    def clear_search(self):
        self.view.entry_search.delete(0, "end")
        self.refresh_table()

    def refresh_table(self):
        self.view.clear_table()
        for student in self.manager.get_all_students():
            self.view.insert_row(*student.get_info())

How add_student() actually flows:

Read entries
↓
Validate
↓
Check duplicate ID
↓
Create Student

Add to manager

Both add_student() and update_student() need the exact same checks. Writing the logic once and calling it twice means one bug fix covers both.
Treeview has no "update all rows" command — the simplest reliable way to keep it in sync with self.manager.students is to wipe it and rebuild it from the Model every time something changes.

main.py — starting the application

main.py doesn't know about buttons or validation. Its only job is to create the three pieces, in order, and start the event loop.

main.py
import tkinter as tk

from views.student_view import StudentView
from controllers.student_controller import StudentController


def main():
    root = tk.Tk()
    view = StudentView(root)
    controller = StudentController(view)
    root.mainloop()


if __name__ == "__main__":
    main()

CRUD

Almost every app that manages records reduces to four operations. Here's each one, mapped to this project.

Read

manager.get_all_students()

manager.update_student(...)

13 · Data safety

Validation

Never trust what a user typed. validate_input() runs before every add or update, in this order:

InputCheckResult
Student ID emptynot student_idError: "Student ID cannot be empty."
Name emptynot nameError: "Name cannot be empty."
Age emptynot ageError: "Age cannot be empty."
Grade emptynot gradeError: "Grade cannot be empty."
Age = "abc"int(age) raises ValueErrorError: "Age must be a number."
Age = "-3" or "0"age_value <= 0Error: "Age must be greater than 0."
Duplicate Student IDmanager.find_student(id) returns a studentError: "This Student ID already exists." (checked in add_student, after validation)
Order matters: emptiness is checked before int(age) is ever called — otherwise converting an empty string to an integer would crash the app instead of showing a clean error.

from models.student import Student
from models.student_manager import StudentManager


class StudentController:

    def __init__(self, view):
        self.view = view
        self.manager = StudentManager()

        self.view.btn_add.config(command=self.add_student)
        self.view.btn_update.config(command=self.update_student)
        self.view.btn_delete.config(command=self.delete_student)
        self.view.btn_clear.config(command=self.clear_form)
        self.view.btn_search.config(command=self.search_student)
        self.view.btn_clear_search.config(command=self.clear_search)

        self.view.tree.bind("<>", self.select_student)

        self.load_sample_data()

    def load_sample_data(self):
        sample_students = [
            Student("S001", "Nguyen Van An", 15, "Grade 9"),
            Student("S002", "Tran Minh Anh", 16, "Grade 10"),
            Student("S003", "Le Hoang Nam", 17, "Grade 11"),
        ]
        for student in sample_students:
            self.manager.add_student(student)
        self.refresh_table()

    def validate_input(self, student_id, name, age, grade):
        if not student_id:
            self.view.show_error("Validation Error", "Student ID cannot be empty.")
            return False
        if not name:
            self.view.show_error("Validation Error", "Name cannot be empty.")
            return False
        if not age:
            self.view.show_error("Validation Error", "Age cannot be empty.")
            return False
        if not grade:
            self.view.show_error("Validation Error", "Grade cannot be empty.")
            return False

        try:
            age_value = int(age)
        except ValueError:
            self.view.show_error("Validation Error", "Age must be a number.")
            return False

        if age_value <= 0:
            self.view.show_error("Validation Error", "Age must be greater than 0.")
            return False

        return True

    def add_student(self):
        student_id, name, age, grade = self.view.get_form_data()

        if not self.validate_input(student_id, name, age, grade):
            return

        if self.manager.find_student(student_id):
            self.view.show_error("Duplicate ID", "This Student ID already exists.")
            return

        student = Student(student_id, name, int(age), grade)
        self.manager.add_student(student)

        self.refresh_table()
        self.clear_form()
        self.view.show_message("Success", "Student added successfully.")

    def update_student(self):
        student_id, name, age, grade = self.view.get_form_data()

        if not self.validate_input(student_id, name, age, grade):
            return

        updated = self.manager.update_student(student_id, name, int(age), grade)

        if not updated:
            self.view.show_error("Not Found", "Student ID not found.")
            return

        self.refresh_table()
        self.clear_form()
        self.view.show_message("Success", "Student updated successfully.")

    def delete_student(self):
        student_id, name, age, grade = self.view.get_form_data()

        if not student_id:
            self.view.show_error("Validation Error", "Select a student to delete.")
            return

        confirmed = self.view.ask_confirmation(
            "Confirm Delete",
            "Delete student " + student_id + "?"
        )

        if not confirmed:
            return

        deleted = self.manager.delete_student(student_id)

        if not deleted:
            self.view.show_error("Not Found", "Student ID not found.")
            return

        self.refresh_table()
        self.clear_form()
        self.view.show_message("Success", "Student deleted successfully.")

    def clear_form(self):
        self.view.clear_form()

    def select_student(self, event):
        selected = self.view.get_selected_item()

        if not selected:
            return

        values = self.view.get_row_values(selected[0])
        self.view.fill_form(*values)

    def search_student(self):
        keyword = self.view.entry_search.get().strip().lower()

        self.view.clear_table()

        for student in self.manager.get_all_students():
            if keyword in student.name.lower():
                self.view.insert_row(*student.get_info())

    def clear_search(self):
        self.view.entry_search.delete(0, "end")
        self.refresh_table()

    def refresh_table(self):
        self.view.clear_table()
        for student in self.manager.get_all_students():
            self.view.insert_row(*student.get_info())
